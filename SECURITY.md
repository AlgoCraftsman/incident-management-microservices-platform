# Security Policy

## Supported Versions

This repository is a reference implementation rather than a hosted service.
Security fixes are applied to the current `main` branch; earlier commits and
unmaintained copies are not supported.

| Version | Supported |
| --- | --- |
| Current `main` | Yes |
| Earlier commits or releases | No |

## Reporting a Vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do
not disclose suspected vulnerabilities, credentials, personal data, or exploit
details in a public issue.

If private vulnerability reporting is unavailable, contact the repository
owner through their GitHub profile and request a private reporting channel
without including sensitive details in the initial message.

Include the affected component, reproduction conditions, potential impact,
and any suggested mitigation. Reports are reviewed on a best-effort basis; the
project does not currently offer a bug bounty or a guaranteed response time.
